# LF Games — Sistema de Gestão (ERP)

Sistema de gestão para a **LF Games** (Votorantim - SP), loja de consoles, jogos, acessórios e periféricos, com vendas físicas, WhatsApp, Instagram e Mercado Livre.

## Stack
- React 19 + Vite (SPA, PWA)
- Firebase (Firestore + Auth anônima)

## Rodando localmente
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
